# 跨项目导演学习库

入口：AI 助手 → 跨项目导演学习库。

学习库收录两类已经经过人工门禁的证据：

- 发布后证据中明确“采纳为下轮参考”的洞察；
- 发布实验对照中明确确认“不是因果证明”并保存的人工结论。

它不会收录尚未审核、已拒绝或只有原始指标的记录，也不会把经验自动写入新工程、导演 Brief、故事选版或生成提示。

## 证据快照与来源

学习记录会保存结论、原证据、人工理由、平台、账号/数据源、内容类型、受众、项目、主题，以及原观察 ID、RC ID、最终成片 SHA-256 和来源确认时间。首次进入 AI 工作台后，已有人工采纳记录会同步进学习库；同一工作台内新采纳洞察或新保存版本对照也会立即同步。

记录一旦入库，即使较老的 RC 因本机历史上限不再可用，证据快照仍会保留。界面会区分：

- `凭证可核对`：当前仍能找到原观察、RC 和匹配哈希；
- `来源暂不可用`：快照保留，但本机已找不到完整原观察或 RC；
- `凭证失配`：仍有对应 RC，但成片哈希与记录不一致，不能继续引用。

学习库最多保存最近 300 条来源证据；不会复制原视频或平台评论原文。

## 时效与检索

证据年龄从原人工确认时间计算：

- 0–60 天：新鲜；
- 61–180 天：衰减；
- 超过 180 天：过期。

衰减或过期不会删除证据，只提醒不能把旧经验当成当前稳定规律。可按关键词、平台、内容类型、时效和证据角色搜索。关键词同时检索结论、证据、人工理由、适用范围、创作假设和分类说明。

## 支持、反例与适用边界

每条记录默认为“未整理”。人工分类时必须：

1. 选择“支持假设”“作为反例”或“仅供参考”；
2. 写出具体创作假设；
3. 写明分类理由、适用范围和不能外推到哪里；
4. 确认已检查来源、适用范围和证据时效。

相同文字的创作假设会聚合显示支持、反例和参考数量。反例不会因支持证据较多而被隐藏，也不会自动生成一条“最终规则”。修改分类只更新学习库整理信息，不改原发布观察或实验结论。

## 验证

- `npm run test:director-learning` 验证跨项目证据投影、范围、搜索、支持/反例分类、证据衰减、凭证状态、同步幂等和原来源只读性。
- 启动 Vite 5199 后运行 `node scripts/test-director-learning-library-ui.mjs`，验证真实界面同步、搜索筛选、支持/反例聚合、独立持久化、刷新恢复，以及当前导演状态不被自动修改。
