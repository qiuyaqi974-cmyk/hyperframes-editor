# 视觉索引测试基准与质量统计

该基准不依赖真实素材，也不调用在线视觉模型。脚本每次在系统临时目录生成固定视频，运行与桌面版相同的 FFmpeg 变化检测和代表帧选择，然后删除临时视频。

运行：

```powershell
npm run benchmark:visual
```

如需保存机器可读报告：

```powershell
npm run benchmark:visual -- --output reports/source-visual-benchmark.json
```

## 固定场景

- 三段纯色硬切：检查 3 秒和 6 秒两个已知变化。
- 静态长镜头：检查无变化时是否误报，并测定期覆盖间隔。
- 缓慢亮度变化：记录传统变化检测是否把渐变当成变化，但不强迫它被解释为硬切。
- 0.5 秒短动作：检查代表帧是否真正落入短暂变化区间，而不只检查是否找到边界。
- 口播与画面冲突夹具：使用固定的“模型候选”和人工答案，统计字段完整性与需要人工纠正的字段；不调用在线模型，也不接受模型自评分。

## 2026-10-03 本机基线

| 场景 | 结果 |
| --- | --- |
| 明显硬切 | 2/2 命中，召回率 100%，精确率 100%，5 张代表帧 |
| 静态长镜头 | 0 次误报，3 张代表帧，最大覆盖间隔 4 秒 |
| 缓慢亮度变化 | 记录到 1 次变化，说明“变化”不能被称为已确认硬切；4 张代表帧 |
| 0.5 秒短动作 | 找到开始变化、漏掉结束变化，边界召回率 50%；唯一代表帧落在动作区间 |
| 口播冲突夹具 | 6/6 字段完整，但动作、结果、标签三项需要人工纠正 |

基准门禁要求明显硬切完整命中、静态长镜头无误报、短动作至少有一张代表帧落入区间、截图数不超过预算，并准确列出固定夹具中的人工纠正项。缓慢变化与短动作结束边界作为已知观察保存，不伪装成已经解决。
