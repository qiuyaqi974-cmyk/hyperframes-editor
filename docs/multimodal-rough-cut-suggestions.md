# 视觉与口播联合粗剪建议

粗剪候选可以把逐词转写和已经人工确认的视觉动作放在一起，给出待审的保留、排除、叙事职责和理由建议。

## 使用范围

- 只读取当前原片中来源签名、时间范围仍然有效，且 `method` 为 `human-observed` 的视觉语义。
- 未经人工确认的在线视觉模型候选不会进入动作索引，因此也不会进入联合建议。
- 同一视觉动作只在对应的人工动作候选上生成建议，避免同时建议保留与它重叠的语音候选。
- “遮挡、模糊、穿帮、失误、废片、无效、重复”等已确认语义只会形成排除建议；不会直接删除片段。

## 人工门禁

联合建议和候选的实际 `decision` 分开保存。用户点击“采纳”后，系统才写入保留/排除决定和建议的叙事职责。采纳不会赋予视觉检查通过状态，也会清除旧的结构确认。

片段写入时间轴前仍必须满足现有门禁：

1. 所有保留片段逐段完成视觉检查；
2. 处理重叠冲突；
3. 完成叙事职责与顺序编排；
4. 明确确认结构；
5. 后续继续完成全局预演和选版流程。

当前建议由透明关键词与时间位置规则生成，不声称理解因果关系。它用于缩小人工审片范围，不代替导演判断。
