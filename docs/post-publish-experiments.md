# 发布实验对照

入口：AI 助手 → 发布实验对照。

这套能力比较两条已经归属到冻结 RC 和最终成片哈希的发布观察。它提供可比性检查和描述性差值，不提供自动赢家，也不把相关性解释为剪辑版本的因果效果。

## 可比性门槛

以下情况会阻止保存比较结论：

- 两条观察相同，来自同一个 RC，或指向同一个发布内容；
- 任一 RC 缺失，或保存的最终成片 SHA-256 与观察记录不一致；
- 平台或账号/数据源不同；
- 观测时间窗的差距超过 6 小时或较短窗口的 20%（取较大值）；
- 导演内容类型、受众、目标或核心表达不同；
- 两侧最终成片哈希相同，实际没有版本变化；
- 没有名称和单位一致的指标。

以下差异不会直接阻止，但会将结果标为“有限可比”，并在人工结论旁永久保留：

- 观测窗口不完全一致；
- 发布时间不同；
- 成片时长相差超过较短版本的 10%；
- 播放样本量相差两倍或以上。

界面同时展示主题、平台/账号、发布时间、观测窗口、片长、播放样本和故事版本。播放量、平均观看、完播、评论聚合以及相差不超过 0.5 秒的留存点，按“基线、对照、描述差值”展示。

## 人工结论

只有没有阻断项的比较可以保存。用户必须写明结论与限制，并勾选“理解这不是因果证明”。保存后形成独立的描述性实验记录，绑定两侧观察 ID、RC ID 和成片哈希。它不会修改：

- 当前导演 Brief；
- 故事选版或冻结方案；
- 任何 RC、渲染报告或成片凭证；
- 原始发布观察和已采纳的单条洞察。

如果后续找不到原观察，或任一 RC 的成片哈希无法匹配，历史结论会标记“版本凭证已失配”，不会静默重连。

## 保存和验证

实验结论使用独立 IndexedDB 键保存，最多保留最近 50 条。同一对观察无论左右顺序如何只能保存一次人工结论。

- `npm run test:post-publish-experiment` 验证平台、账号、主题、窗口、发布内容、哈希和指标门槛，限制提示、差值、非因果确认、重复防护和只读性。
- 启动 Vite 5199 后运行 `node scripts/test-post-publish-experiment-ui.mjs`，验证真实界面比较、差值展示、人工确认、独立持久化、刷新恢复和导演/RC 隔离。
