# 本地画面索引试版

长视频源素材台的“本地画面索引”使用已打包 FFmpeg，在本机以每秒 2 帧、160px 宽的低分辨率画面寻找明显变化，再按时间窗选择截图。每个时间窗至少有一张候选图；附近有变化点时优先取变化后的画面。用户可选择 10/20/30 秒期望间隔和 12/24/48 张截图预算。视频很长时预算优先，界面会显示实际平均间隔与覆盖不足提示。

截图为 320px 宽 JPEG，连同时间窗内的现有转写文本展示在素材台，点击时间可回看原片。扫描结果与截图缓存在桌面版用户数据目录，缓存键包含原片路径、大小、修改时间及采样参数。不会上传原片或截图，不调用视觉 AI，不修改原片、动作索引、粗剪方案或人工确认。

本版只能寻找明显画面变化，不能理解动作含义。快速动作、缓慢变化、镜头晃动和无切换长镜头可能造成漏检或误检；定期覆盖帧只是兜底。截图与口播是待审线索，仍需人工观看并通过现有视觉门禁。下一阶段如需自动画面描述，应单独设计模型调用、隐私与成本预算，不把当前图像直接当作已确认语义。
