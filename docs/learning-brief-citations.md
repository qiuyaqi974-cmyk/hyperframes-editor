# 学习证据受控引用

跨项目导演学习库可以把人工分类的学习记录组织成一份可审查的导演 Brief 建议，但不会自动改写当前工程。

## 使用流程

1. 在学习库中勾选支持、反例和背景证据。
2. 选择“生成 Brief 建议”。系统会检查同一假设下是否有遗漏的反例，并重新核验观察、RC 与成片 SHA-256。
3. 阅读每条引用的证据角色、适用范围、时效、观察 ID、RC ID 和成片哈希。
4. 逐项勾选要更新的 Brief 字段，可以在应用前编辑建议值。
5. 填写证据为什么适用于当前工程及不能外推的边界，再确认应用。

## 安全边界

- 凭证失配或原观察、RC 不可核验时，建议会被阻止。
- 同一创作假设存在已知反例但未纳入时，建议会被阻止。
- 超过 180 天的记录会标记为过期，必须额外确认才能引用。
- 只有支持证据能够推出字段建议；反例和背景用于限制结论。
- 未勾选的 Brief 字段保持原值。
- 应用后在导演决策层保留引用快照，包含证据角色、范围、时效和凭证。
- 一次应用只产生一个文档历史步骤，可通过全局撤销完整恢复。
- 引用快照是本次决策的审计记录，不会把历史经验固化为永久规则。
