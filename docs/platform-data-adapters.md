# 发布数据平台适配器

发布数据平台适配器位于 AI 工作台的“发布后证据”面板。它读取平台导出的 CSV、TSV、XLSX 或 JSON 文件，可以把用户明确确认的一行数据转换为标准发布观察，也可以通过已确认模板安全导入完整批次。

适配器只读取本地文件，不请求平台账号权限，不连接平台 API，也不上传文件。

## 文件要求

- CSV / TSV：首行为唯一表头，支持引号、逗号和制表符；
- XLSX：读取第一个工作表，首行为表头；
- JSON：顶层必须是对象数组，或使用明确的 `{ "rows": [...] }`；不会猜测 `data`、`list` 等嵌套字段。

文件读取后显示文件名、格式、数据行数、列数和完整文件 SHA-256。重复表头、空表和含义不明确的 JSON 结构会直接拒绝。

## 映射门禁

系统会按常见中英文列名给出目标字段建议。建议只用于减少选择步骤，仍显示为“待确认建议”，不会直接保存。用户必须明确完成并确认：

- 冻结 RC；RC 必须有最终成片 SHA-256；
- 平台和账号/数据源标识；
- 要导入的数据行；
- 发布链接或内容 ID；
- 发布时间；
- 观测时间，来自明确映射字段或手工填写；
- 至少一项发布指标；
- 每个指标的单位；
- 不导入的源字段。

同一目标字段不能由多个源字段重复提供。播放量和评论数使用整数；平均观看使用秒；完播率必须明确选择“百分数 0–100”或“比例 0–1”；留存曲线也必须明确选择百分数或比例。适配器不会根据数值大小猜测单位。

## 保存的来源凭证

转换后的发布观察除现有 RC、成片哈希、平台、账号、内容 ID、发布时间和观测时间外，还保存：

- 源文件名；
- 源文件完整 SHA-256；
- 所选数据行索引；
- 每个源字段对应的目标字段和单位；
- 明确忽略的字段；
- 人工确认映射的时间。

转换只生成标准观察和待审洞察，不自动采纳洞察，不修改导演 Brief、冻结方案、RC 或成片凭证。

## 映射模板

- 模板只有在用户确认当前字段、单位、平台和账号后才能保存；
- 模板保存文件格式、完整表头、字段映射、单位、平台和账号，不保存 RC、内容 ID或任何具体行时间；
- 安全批次模板必须明确映射内容 ID、发布时间、观测时间和至少一项指标；
- 套用时要求文件格式与完整表头一致。字段缺失、多出字段、重复目标或未知单位都会拒绝套用；
- 模板独立保存在本机，最多保留 20 个，可人工删除。

## 安全批次导入

批次模式覆盖文件中的全部数据行，不提供跳过错误行的入口。每一行都会展示内容 ID、发布时间、观测时间和时间窗，并要求单独选择冻结 RC、核对成片哈希后人工确认。

以下任一情况都会阻止整批保存，已经合格的行也不会提前写入：

- 任一行未选择 RC 或未人工确认；
- 内容 ID、发布时间、观测时间或指标缺失、格式无效；
- 指标单位未知或与目标字段不适用；
- 批次内出现相同 RC、内容 ID 和观测时间；
- 与本机已有观察发生相同 RC、内容 ID 和观测时间冲突；
- 批次超过 100 行，或保存后超过 100 条观察的安全上限。

整批通过后才一次写入本地观察库。每一行继续保留自己的源文件 SHA-256、行号、字段/单位映射、忽略列和人工确认时间。同一事务还会写入不可变批次会话，保存文件格式、映射模板完整快照、统一确认时间，以及每行观察 ID、RC、成片哈希、内容 ID 和时间。

## 批次会话与整体回滚

发布后证据面板会保留每个安全批次的独立会话。映射模板之后即使被修改或删除，会话中的模板快照和逐行回执仍保持原样。

“检查整批回滚影响”会重新读取当前发布观察、实验结论、导演学习、当前 Brief 引用和所有冻结 RC 快照中的 Brief 引用：

- 批次任一观察缺失、内容与会话回执漂移、同时归属多个会话，都会阻断；
- 任一洞察已经人工采纳、任一实验引用批次观察、任一学习记录来源于批次，或任一当前/冻结 Brief 引用批次，都会阻断；
- 只有全部观察仍是未被下游使用的原始状态，填写原因并确认完整影响清单后，才能整体撤销；
- 提交时会再次读取全部关系，避免预览后新增引用绕过门禁；
- 回滚在一个事务中删除该会话的全部观察并追加独立回滚回执。原始会话永久保留，不允许部分删除或重复回滚。

批次会话和回滚回执当前保存在本机 IndexedDB，各自达到 100 条时停止新增，避免静默丢弃审计记录。工程归档格式目前尚未包含这两类本机操作回执。

## 验证

```powershell
npm run test:platform-adapter
npm run test:post-publish-batch
npm run test:platform-adapter-ui
```

领域测试覆盖 CSV、XLSX、JSON、文件哈希、字段建议、单位转换、重复映射、模板创建/套用、表头与未知单位阻断、逐行确认、批内/已有观察冲突、不可变会话、完整回滚，以及采纳洞察/实验/学习/Brief 四类阻断。隔离 Edge 测试覆盖真实文件选择、单行导入、模板持久化、逐行 RC/时间确认、观察与会话原子写入、影响清单、整批回滚回执，以及 RC 与导演状态保持不变。
